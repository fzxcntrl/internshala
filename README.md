# Internshala Search Page

A React-based replica of the [Internshala internships search page](https://internshala.com/internships/) built as part of the SDE (Web) Internship assignment.

## Features
- 🔍 Smart search bar with suggestion chips (search by role, company, skill, or location)
- 🔖 Save & bookmark internships with localStorage persistence
- 🎛️ Filters — Profile, Location, Duration, Minimum Stipend
- 📊 Sort by Relevance, Newest First, Highest Stipend
- ⬆️ Back to top button
- 📱 Fully responsive design

## Tech Stack
React, Vite, Tailwind CSS, Heroicons, Axios

## Setup
```bash
npm install
npm run dev
```
